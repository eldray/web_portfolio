# Emmanuel Appiah - Full-Stack Developer Portfolio

![Portfolio Preview](https://images.unsplash.com/photo-1580927752452-89d86da3fa0a?ixlib=rb-4.0.3&ixid=M3wxMjA3fDB8MHxwaG90by1wYWdlfHx8fGVufDB8fHx8fA%3D%3D&auto=format&fit=crop&w=880&q=80)

This is a modern and responsive portfolio website for **Kwame Asante**, a Full-Stack Developer based in Ghana. The project is built using **Vite**, **React**, and **Tailwind CSS** to ensure a clean, modular, and maintainable codebase.

## Features

- **Responsive Design**: Fully optimized for mobile, tablet, and desktop.
- **Smooth Scrolling**: Smooth navigation between sections.
- **Interactive Animations**: Hover effects and animations for buttons, icons, and cards.
- **Modular Components**: Each section (Hero, About, Skills, etc.) is built as reusable React components.
- **Dark Theme**: A sleek dark theme with gradient accents for a professional look.
- **Wave Animation**: A waving hand emoji in the hero section for a friendly touch.
- **Project Showcase**: Displays recent projects with live demo and GitHub links.
- **Contact Form**: Includes a form for visitors to send messages directly.

---

## Tech Stack

- **Frontend Framework**: React
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Font Awesome 6
- **Animations**: Custom CSS animations (wave effect) and Tailwind transitions
- **Responsive Design**: Tailwind's utility-first approach

## Installation

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/kwame-portfolio.git
   cd kwame-portfolio
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the project in your browser:
   ```
   http://localhost:5173
   ```

---

## Usage

### Development

- Run the development server:
  ```bash
  npm run dev
  ```

### Production Build

- Generate a production-ready build:

  ```bash
  npm run build
  ```

- Serve the build locally (optional):
  ```bash
  npm run preview
  ```

### Deployment

This project can be deployed to platforms like **Netlify**, **Vercel**, or **GitHub Pages**. Ensure you build the project (`npm run build`) before deploying.
